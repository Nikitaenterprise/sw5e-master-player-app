# SW5e Master & Player App

Застосунок для **офлайнових** сесій Star Wars 5e. Гравці сидять за одним столом із
майстром. На ноутбуці майстра підіймається локальний сервер: майстер працює на
ноутбуці, гравці відкривають свої листи персонажів у браузерах телефонів через
локальну мережу. **Інтернет не потрібен.**

Замінює: вкладку з книгою правил, вкладку з лутом, листи в акаунті на sw5e.com,
Excel з ініціативою, лист корабля в PowerPoint і обмін JSON-файлами в Телеграмі.

Це **не** VTT: карт, фішок і туману війни немає. Кубики кидають руками — застосунок
каже, який кубик і з яким модифікатором, результат вводить людина.

## Як це зроблено

Node 22, TypeScript, Vite + React, Vitest. Нуль нативних залежностей: застосунок
мусить встановитись на Windows без Build Tools.

Чотири рішення, на яких усе тримається (повні — в `docs/decisions/`):

1. Формат експорту sw5e.com — наш рідний формат, без конвертації.
2. Журнал подій — єдине джерело правди. Звідси сповіщення майстру про зміни
   гравців, відкат, історія сесії та стійкість до вимкнення живлення.
3. Обчислюване ніколи не зберігається. На диску лише вибори людини — тому зміни
   застосунку не скидають персонажів.
4. Нуль нативних залежностей.

## Стан

Фаза 0, фундамент. Закомічено: структура й процес, п'ять справжніх листів
персонажів, 7 885 документів правил, схема персонажа, шаблони золотого тесту.
Коду застосунку ще немає — наступне: сервер і демо на чотирьох екранах.

Актуальний стан завжди в `docs/ПРОГРЕС.md`.

пов'язана з Disney чи Wizards of the Coast. Дані правил узяті з MIT-проєкту
`christopherfowers/sw5e-database`; походження з хешами комітів — `vendor/SOURCES.md`.
Застосунок некомерційний, для одного стола.
