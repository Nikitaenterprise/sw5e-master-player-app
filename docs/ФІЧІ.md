# Реєстр фіч

Правила роботи з цим файлом — `docs/ПРОЦЕС.md`. Нічого поза реєстром не існує.
Статуси: `черга` → `в роботі` → `готова` → `прийнята` (останнє ставить лише власник).

Фічі з черги описані одним рядком. Коли фічу беруть у роботу, її запис розгортають:
додають перевірку словами власника й перелік тестів.

---

## Фаза 0 · Фундамент

### F-001 · Каркас репозиторію і правила роботи
**Статус:** готова · **Коміт:** `—`
**Що:** структура тек, `CLAUDE.md`, процес, цей реєстр, рішення, чотири `.bat`.
**Перевірка власником:** склонуй репозиторій у порожню теку на будь-якому комп'ютері,
відкрий `CLAUDE.md`. Має бути зрозуміло, що це за проєкт і що робити далі, без мене.
**Тести:** `tools/перевірити-структуру.mjs` — усі обов'язкові файли й теки на місці.

### F-002 · Вихідні експорти п'яти персонажів у репозиторії
**Статус:** готова · **Коміт:** `—`
**Що:** п'ять листів зі sw5e.com у `state/characters/source-exports/`, щоб репозиторій
був самодостатнім. Сандру відновлено після пошкодження лапок.
**Перевірка власником:** відкрий будь-який файл у теці — має бути читабельний JSON
із правильним іменем персонажа.
**Тести:** `tools/перевірити-структуру.mjs` — усі п'ять парсяться, у кожного є
`classes`, `baseAbilityScores`, `currentStats`.

### F-003 · Архів даних правил у `vendor/`
**Статус:** в роботі
**Що:** MIT-база `sw5e-database` і компендіум Foundry, вкопійовані з фіксацією SHA.

### F-004 · Схема сирого персонажа
**Статус:** в роботі
**Що:** типи формату sw5e.com, виведені з п'яти реальних файлів, + поділ на
довговічні вибори / стан сесії / метадані.

### F-005 · Шаблони золотого тесту
**Статус:** в роботі
**Що:** п'ять файлів `tests/golden/*.expected.json` із полями під правильні числа
та інструкція для власника, як їх заповнити.

### F-006 · Нормалізований компендіум і індекс пошуку
**Статус:** черга
**Що:** викинути `*Json`-дублі й `*Enum`, почистити кракозябри, зібрати пошук.

### F-007 · Архів легасі Azure API
**Статус:** заблоковано — потрібна машина власника
**Що:** 33 ендпоінти, 14 МБ, із маніфестом SHA-256. Ні контейнер, ні VM не бачать
`azurewebsites.net`; запускати `tools/архів-azure.bat` власноруч.
