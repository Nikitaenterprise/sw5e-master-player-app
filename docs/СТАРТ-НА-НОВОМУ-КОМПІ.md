# Старт на новому комп'ютері

Репозиторій самодостатній. Для роботи не потрібні ні sw5e.com, ні тека на десктопі
власника, ні інтернет після першого встановлення.

## Для власника

1. Встанови **Node 22.12 або новіший** — nodejs.org, кнопка LTS, далі «Далі-Далі-Готово».
2. Встанови **Git** — git-scm.com, так само.
3. Склонуй репозиторій або розпакуй архів у будь-яку теку.
4. Подвійний клік на **`ВСТАНОВИТИ.bat`**. Один раз, хвилина-дві.
5. Подвійний клік на **`ЗАПУСТИТИ.bat`**. Відкриється екран майстра й покажеться QR
   для телефонів.

Перевірити, що все живе, не чекаючи сесії: **`ТЕСТ-4-ЕКРАНИ.bat`**. Відкриється одне
вікно з чотирма екранами — майстер і три гравці. Поміняй ХП у гравця — має змінитись
у майстра.

Якщо щось зламалось після чиїхось змін — `docs/ЯК-ВІДКАТИТИ.md`.

## На Mac

Ті самі чотири запускачі є і для Mac: поруч із кожним `.bat` лежить `.command` з тим
самим іменем (F-092). Подвійний клік відкриває Термінал, і далі все як на Windows:
**`ВСТАНОВИТИ.command`** один раз, потім **`ЗАПУСТИТИ.command`** перед сесією,
**`ТЕСТ-4-ЕКРАНИ.command`** і **`ПЕРЕВІРИТИ.command`** — коли треба.

1. Node 22.12 або новіший — nodejs.org, кнопка LTS (або `brew install node`).
2. Репозиторій — краще `git clone`, ніж архів: архів, скачаний браузером, macOS
   позначає як «з інтернету», і запускачі тоді не відкриваються подвійним кліком.
   Якщо так сталося: відкрий **Системні параметри → Конфіденційність і безпека**, знайди
   внизу рядок про заблокований файл і натисни **«Усе одно відкрити»**. Один раз на
   кожен файл.
3. Якщо Термінал спитає дозволу на теку «Документи» чи «Завантаження» — дозволь:
   інакше він не дістанеться до файлів застосунку.
4. Після роботи закрий вікно Термінала або натисни в ньому `Ctrl+C` — сервер
   зупиниться.

Одну й ту саму теку не варто відкривати по черзі з Windows і з Mac: `node_modules` у
них різні. Якщо так вийшло — просто запусти `ВСТАНОВИТИ` ще раз, він ставить начисто.

## Для сесії АІ

1. `CLAUDE.md` — що це за проєкт, архітектура, заборони.
2. `docs/ПРОГРЕС.md` — де ми зараз, що далі, що блокує.
3. `docs/ФІЧІ.md` — черга. Візьми наступну незаблоковану, не вибирай свою.
4. `docs/ПРОЦЕС.md` — Definition of Done. Фіча без тестів не існує.

Нічого іншого на старті читати не треба. Зокрема **не** читай `vendor/` і `reference/`
у контекст: це десятки мегабайт.

Середовище розробки: `npm install`, далі `npm run check` має бути зеленим на чистому
клоні. Якщо ні — це перша задача, і вона важливіша за будь-яку фічу.

**У теці власника `npm install` запускає тільки власник** (`ВСТАНОВИТИ.bat`). Цю теку
монтують у середовище АІ, тому одна `node_modules` обслуговувала б дві різні
операційні системи — так уже ламався запуск. Сесія АІ копіює джерела в окрему теку,
ставить залежності там і там же запускає перевірки. Деталі — у `CLAUDE.md`.
