# Старт на новому комп'ютері

Репозиторій самодостатній. Для роботи не потрібні ні sw5e.com, ні тека на десктопі
власника, ні інтернет після першого встановлення.

## Для власника

1. Встанови **Node 22 або новіший** — nodejs.org, кнопка LTS, далі «Далі-Далі-Готово».
2. Встанови **Git** — git-scm.com, так само.
3. Склонуй репозиторій або розпакуй архів у будь-яку теку.
4. Подвійний клік на **`ВСТАНОВИТИ.bat`**. Один раз, хвилина-дві.
5. Подвійний клік на **`ЗАПУСТИТИ.bat`**. Відкриється екран майстра й покажеться QR
   для телефонів.

Перевірити, що все живе, не чекаючи сесії: **`ТЕСТ-4-ЕКРАНИ.bat`**. Відкриється одне
вікно з чотирма екранами — майстер і три гравці. Поміняй ХП у гравця — має змінитись
у майстра.

Якщо щось зламалось після чиїхось змін — `docs/ЯК-ВІДКАТИТИ.md`.

## Для сесії АІ

1. `CLAUDE.md` — що це за проєкт, архітектура, заборони.
2. `docs/ПРОГРЕС.md` — де ми зараз, що далі, що блокує.
3. `docs/ФІЧІ.md` — черга. Візьми наступну незаблоковану, не вибирай свою.
4. `docs/ПРОЦЕС.md` — Definition of Done. Фіча без тестів не існує.

Нічого іншого на старті читати не треба. Зокрема **не** читай `vendor/` і `reference/`
у контекст: це десятки мегабайт.

Середовище розробки: `npm install`, далі `npm run check` має бути зеленим на чистому
клоні. Якщо ні — це перша задача, і вона важливіша за будь-яку фічу.
