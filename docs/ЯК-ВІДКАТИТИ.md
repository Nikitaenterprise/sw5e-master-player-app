# Як відкатити, якщо все зламалось

Для власника. Нічого страшного статись не може: кожна фіча — окремий коміт, і будь-що
можна повернути.

## Якщо `ПЕРЕВІРИТИ.bat` червоний

Відкрий командний рядок у теці проєкту (Shift + правий клік на теці → «Відкрити вікно
PowerShell тут») і вставляй по одному рядку.

**Повернутись до останнього робочого стану, викинувши незакомічені зміни:**

```
git checkout -- .
```

**Відкотити останню фічу цілком:**

```
git revert HEAD --no-edit
```

Потім запусти `ПЕРЕВІРИТИ.bat` знову. Якщо зелене — готово.

**Подивитись, що взагалі відбувалось:**

```
git log --oneline -20
```

Побачиш список фіч, останні зверху: `F-012 Рушій: базові характеристики` і так далі.

**Відкотити конкретну фічу** (візьми її номер коміту з переліку вище, перші 7 знаків):

```
git revert a1b2c3d --no-edit
```

## Якщо `git status` показує «змінено» на весь репозиторій

Це не твої зміни — це кінці рядків: якийсь редактор перезаписав файли по-своєму.
Відкочувати нічого не треба, просто:

```
git add --renormalize .
git status
```

У списку лишиться тільки те, що змінилось по суті. Якщо лишилось порожньо — змін і
не було. Чому так буває — `docs/ПРОГРЕС.md`, розділ «Відомі пастки».

## Якщо зникли персонажі

Вони не зникають: `state/characters/source-exports/` закомічено в репозиторій, і
вихідні експорти зі sw5e.com лежать там незмінними. Повернути:

```
git checkout HEAD -- state/characters/
```

## Якщо нічого не допомогло

Видали теку й склонуй репозиторій заново — `docs/СТАРТ-НА-НОВОМУ-КОМПІ.md`.
Усе потрібне в репозиторії; нічого цінного поза ним не лежить.
