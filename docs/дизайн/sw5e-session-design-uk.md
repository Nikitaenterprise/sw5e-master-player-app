# Holotable — дизайн-документ веб-компаньйона для сесій SW5e

> **Увага, це чернетка-референс, а не канон.** Її писала окрема сесія, яка не бачила
> цього застосунку. Чинне з неї лише те, що перенесено в
> `docs/дизайн/ДИЗАЙН-ІНТЕРФЕЙСУ.md` (розділ 13 там — що взято, що відкинуто й чому).
> Зокрема **не чинні:** кубики й кидки в застосунку та «застосунок рахує сам» (ADR 0007),
> Laravel/Vue/PWA, шрифти з Google Fonts, модель даних. Лежить тут без змін як джерело.

> Версія 0.1 · 2026-11-28 · Статус: чернетка
> Система: SW5e (Star Wars 5e, sw5e.com) · Платформи: телефон, ноутбук (адаптивний PWA)

---

## 1. Мета

Вебзастосунок, який лежить на столі (фізичному чи віртуальному) під час сесії ДнД у світі SW5e і замінює паперові аркуші, калькулятор очок і блокнот майстра.

**Завдання, які розв'язуємо:**
- Гравець за 2 секунди бачить свої HP, AC, очки Сили/техніки й кидає кубик.
- Майстер веде ініціативу, HP супротивників і стани, не гортаючи PDF.
- Усі бачать спільний бій (порядок ходів, хто поранений) у реальному часі.
- Правила SW5e (сили, техніка, стани) доступні одним тапом.

**Не-цілі (v1):** мапа/тактичне поле, відеозв'язок, конструктор персонажа «з нуля» за всіма книгами, монетизація.

## 2. Користувачі та контекст

| Роль | Пристрій | Контекст | Головне |
|---|---|---|---|
| Гравець | Телефон, однією рукою | Сидить за столом, увага на грі | Свій аркуш, кидки, витрата очок |
| Майстер (GM) | Ноутбук, інколи планшет | Веде бій, нотатки, NPC | Ініціатива, HP ворогів, довідник |
| Гравець онлайн | Ноутбук | Грає через Discord | Аркуш + спільний екран бою поруч |

**Сценарії (user stories):**
1. *Гравець:* «Мій хід — відкриваю застосунок, тисну атаку бластером, бачу результат і шкоду, позначаю витрачений tech point».
2. *Гравець-форсюзер:* «Хочу застосувати силу 2-го рівня — застосунок сам списує 3 очки Сили й показує залишок».
3. *GM:* «Починаю бій: додаю 4 штурмовиків із шаблону, кидаю всім ініціативу однією кнопкою, перемикаю хід».
4. *GM:* «Гравець питає, що робить стан *Shocked* — знаходжу за 3 секунди».
5. *Усі:* «Короткий відпочинок — tech points відновилися автоматично, force points — ні».

## 3. Принципи дизайну

1. **Спершу стіл, потім атмосфера.** Зорі й світлові мечі — це декор. Читабельність чисел і швидкість дій важливіші.
2. **Один великий палець.** На телефоні всі часті дії в нижній третині екрана, цілі ≥ 48×48 px.
3. **Нуль підрахунків у голові.** Модифікатори, вартість сил, відновлення під час відпочинку застосунок рахує сам.
4. **Темна тема за замовчуванням.** Гра часто відбувається ввечері, за приглушеного світла.
5. **Працює без мережі.** Аркуш персонажа й кубики доступні офлайн, синхронізація — коли мережа повернулася.

## 4. Механіки SW5e, що впливають на інтерфейс

Ключові відмінності від класичного D&D 5e, які треба відобразити в UI:

| Механіка | Правило | Як відображаємо |
|---|---|---|
| Forcecasting | Мудрість/Харизма, **Force Points**, відновлюються на **довгому** відпочинку | Синій/фіолетовий лічильник, окрема вкладка «Сила» |
| Techcasting | Інтелект, **Tech Points**, відновлюються на **короткому** відпочинку | Бурштиновий лічильник, вкладка «Техніка» |
| Вартість сили | Сила рівня N коштує **N + 1** очок (point-based варіант із DMG) | Кнопка «Застосувати» показує вартість і блокується, якщо очок замало |
| Max Power Level | Обмеження рівня сили за рівнем класу | Сили вище ліміту — сірі, з підказкою |
| Overcharge | Силу можна посилити, витративши більше очок | Слайдер рівня під час застосування |
| Два види кастингу | Force і Tech суворо розділені | Дві різні вкладки й пули, ніколи не змішуємо |
| Світогляд Сили | Сили світлого / темного / універсального боку | Мітка-колір на картці сили |
| Типи шкоди | Radiant → **energy**, thunder → **sonic** | Іконки й словник шкоди SW5e |
| Валюта | **Кредити** (≈ 1 gp = 10 cr) | Поле «Кредити» в інвентарі |
| Класи | 10: Berserker, Consular, Engineer, Fighter, Guardian, Monk, Operative, Scholar, Scout, Sentinel | Іконка й акцентний колір класу |
| Зорельоти | Окремий модуль Starships of the Galaxy | v2: вкладка «Корабель» |

> Перед реалізацією звірити формули й таблиці з актуальними правилами на sw5e.com. Сайт оновлюється, і частина правил відрізняється від ранніх PDF.

## 5. Інформаційна архітектура

```
Holotable
├── Кампанії
│   └── Кампанія
│       ├── Сесія (live)
│       │   ├── Бій: трекер ініціативи
│       │   ├── Лог кидків
│       │   └── Нотатки сесії
│       ├── Персонажі партії
│       ├── NPC і вороги (шаблони)
│       └── Нотатки кампанії
├── Мій персонаж
│   ├── Огляд (HP, AC, швидкість, очки)
│   ├── Дії (атаки, вміння)
│   ├── Сила
│   ├── Техніка
│   ├── Навички та рятівні кидки
```

**Навігація:**
- **Телефон:** нижній таб-бар із 4 пунктів — `Персонаж · Бій · Кубики · Довідник`. Плаваюча кнопка кидка d20 праворуч над таб-баром.
- **Ноутбук:** лівий сайдбар (згортається) + основна область + права панель контексту (лог кидків / деталі вибраного).

## 6. Ключові екрани

### 6.1 Аркуш персонажа — «Огляд»

**Телефон (360–430 px):**
```
┌─────────────────────────────┐
│ ◄  Kael Voss · Sentinel 5   │  шапка, sticky
├─────────────────────────────┤
│  HP ████████░░  32 / 41  [±]│  велика смуга, тап = редактор HP
│  AC 16   Ініц +3   Швид 30  │
├─────────────────────────────┤
│  ◆ Force   ●●●●●●○○○  6/9   │  тап по точках = витрата
│  ◆ Tech    —                │  прихований, якщо пулу немає
├─────────────────────────────┤
│  Стани: [Poisoned ×]        │
├─────────────────────────────┤
│  Швидкі дії                 │
│  [Saberstaff  +7 | 1d8+4]   │  картки, тап = кидок
│  [Blaster pistol +6 | 1d6+3]│
│  [Force: Battle Insight  2] │
├─────────────────────────────┤
│ Персонаж  Бій  Кубики  Дов. │  таб-бар
└─────────────────────────────┘
                         (d20)  FAB
```

**Ноутбук (≥ 1024 px):** три колонки.
- Ліворуч: характеристики, рятівні кидки, навички.
- Центр: HP/AC/очки, дії, вкладки Сила/Техніка/Інвентар.
- Праворуч: лог кидків і стани.

### 6.2 Застосування сили / техніки

Bottom sheet на телефоні, модальне вікно на ноутбуці.

```
┌─────────────────────────────┐
│ Force Push · Universal      │
│ Рівень: [1]──●──[3]         │  overcharge-слайдер до Max Power Level
│ Вартість: 3 очки (лишилось 6)│
│ Рятівний кидок: STR, Скл 15 │
│ Конц.: ні · Час: дія        │
│ ▸ Опис                      │
│ [ Застосувати й кинути ]    │  основна кнопка, низ екрана
└─────────────────────────────┘
```
Правила: кнопка disabled, якщо очок < вартості. Після застосування — тост «−3 Force · лишилось 3» з кнопкою «Скасувати» (5 с).

### 6.3 Трекер ініціативи (спільний екран бою)

```
┌─────────────────────────────┐
│ Раунд 3          [Наст. ►]  │
├─────────────────────────────┤
│ ▶ 21  Kael Voss     32/41   │  активний: світлова рамка
│   18  Stormtrooper 1  ██░ ⚠ │  вороги: у гравців лише смуга HP, без чисел
│   15  Rix (Engineer) 22/28  │
│   12  Stormtrooper 2  ███   │
│    8  Droid IG-7     ✕ мертвий│
└─────────────────────────────┘
```
- **GM:** drag-n-drop порядку, свайп ліворуч — шкода/лікування, свайп праворуч — стан, «+» — додати із шаблону, «Кинути ініціативу всім NPC».
- **Гравець:** лише перегляд плюс своя картка. Коли настає його хід — вібрація й банер «Ваш хід».
- На ноутбуці в GM трекер ліворуч, картка вибраного ворога (статблок) праворуч.

### 6.4 Кубики

- Сітка кнопок d4 · d6 · d8 · d10 · d12 · d20 · d100. Поле формули (`2d6+3`), перевага/перешкода.
- Результат великим у центрі, розбивка дрібно: `[4, 2] + 3 = 9`.
- Натуральна 20 — короткий спалах «гіперстрибка» (≤ 600 мс), натуральна 1 — червона пульсація.
- Перемикач «Кидок бачать усі / лише GM» (приховані кидки).

### 6.5 Довідник

- Пошук із першого символу, фільтри: Стани · Force · Tech · Зброя · Броня.
- Картка сили: рівень, бік Сили (мітка), час, дистанція, тривалість, концентрація, опис.
- Унизу кожної картки — посилання на першоджерело на sw5e.com.

### 6.6 GM-панель (лише ноутбук, на телефоні — спрощено)

- Шаблони ворогів (клонувати N штук з автонумерацією).
- Нотатки сесії з часовими мітками.
- Кнопки «Короткий відпочинок» / «Довгий відпочинок» для всієї партії: tech points відновлюються на короткому, force points — на довгому.

## 7. Адаптивність

| Breakpoint | Ширина | Розкладка |
|---|---|---|
| `xs` | < 480 px | 1 колонка, таб-бар унизу, bottom sheets |
| `sm` | 480–767 px | 1 колонка, ширші картки, 2 колонки навичок |
| `md` | 768–1023 px | 2 колонки, таб-бар → бічний rail |
| `lg` | 1024–1439 px | Сайдбар + контент + права панель |
| `xl` | ≥ 1440 px | Те саме, max-width контенту 1440 px, по краях — зоряне тло |

**Правила:**
- Mobile-first CSS, контейнерні запити (`@container`) для карток.
- Враховуємо safe-area (`env(safe-area-inset-*)`) під вирізи й жестову панель.
- Ландшафт на телефоні: дві колонки (огляд + дії).
- На ноутбуці гарячі клавіші: `R` — кидок d20, `N` — наступний хід, `/` — пошук у довіднику, `1–9` — швидкі дії.
- Hover-стани лише під `@media (hover: hover)`, щоб на сенсорних пристроях нічого не «залипало».

## 8. Візуальна мова

### 8.1 Настрій
Інтерфейс голографічного столу: темний космос, тонкі світні лінії, моноширинні цифри «бортового комп'ютера». Це натхнення, а не копія: жодних логотипів, кадрів із фільмів і персонажів франшизи.

### 8.2 Кольорові токени

```css
:root {
  /* Поверхні */
  --bg:            #07090F;  /* космос */
  --surface-1:     #0E1320;  /* картки */
  --surface-2:     #161D2E;  /* підняті / sheets */
  --border:        #24304A;
  --text:          #E6ECF5;
  --text-muted:    #8C9AB3;

  /* Акценти (кольори клинків) */
  --accent-blue:   #4FB4FF;  /* основний, посилання, фокус */
  --accent-green:  #4BE38A;  /* лікування, успіх */
  --accent-red:    #FF4D5E;  /* шкода, крит. провал, темний бік */
  --accent-purple: #B07CFF;  /* Force points */
  --accent-amber:  #FFB547;  /* Tech points, попередження */

  /* Семантика */
  --hp:            var(--accent-green);
  --hp-low:        var(--accent-amber);   /* ≤ 50 % */
  --hp-critical:   var(--accent-red);     /* ≤ 25 % */
  --force:         var(--accent-purple);
  --tech:          var(--accent-amber);
  --side-light:    var(--accent-blue);
  --side-dark:     var(--accent-red);
  --side-universal:#9FB0C8;

  /* Світіння */
  --glow-sm: 0 0 6px  color-mix(in srgb, currentColor 60%, transparent);
  --glow-md: 0 0 14px color-mix(in srgb, currentColor 45%, transparent);
}
```
Усі пари текст/тло перевірити на контраст WCAG AA (≥ 4.5:1 для тексту). Колір ніколи не єдиний носій змісту: у HP — число, у боку Сили — текстова мітка.

### 8.3 Типографіка

| Роль | Шрифт | Розмір (mobile / desktop) |
|---|---|---|
| Заголовки | **Orbitron** або **Exo 2** (Google Fonts, OFL, Exo 2 має кирилицю) | 20 / 24 px |
| Текст | **Inter** (OFL, кирилиця) | 16 / 15 px |
| Цифри (HP, AC, кидки) | **JetBrains Mono** (OFL), `font-variant-numeric: tabular-nums` | 28–48 px |
| Декор | **Aurebesh AF** (Public domain / OFL) — лише орнамент: підписи-пасхалки, тло | — |

Aurebesh не використовуємо для значущого тексту: його ніхто не читає швидко.

> Orbitron не має кирилиці — для українських заголовків брати Exo 2.

### 8.4 Іконки
- Базовий набір: **Lucide** або **Tabler Icons** (MIT).
- Власні іконки класів і типів шкоди (energy, ion, sonic, kinetic, acid, cold, fire, lightning, necrotic, poison, psychic) малюємо в єдиному стилі: лінія 1.5 px, заокруглені кінці.

### 8.5 Рух

| Елемент | Анімація | Тривалість |
|---|---|---|
| Тло `xl` | Повільний паралакс зірок (canvas) | постійно, ≤ 30 fps |
| Перемикачі | «Світловий меч»: клинок висувається (scaleY) + glow | 200 мс |
| Активний хід | Пульсуюча рамка `--accent-blue` | 2 с, цикл |
| Nat 20 | Зорі витягуються в лінії (hyperspace) | ≤ 600 мс |
| Шкода | Смуга HP зсувається, спалах `--accent-red` | 250 мс |

`prefers-reduced-motion: reduce` → усі декоративні анімації вимкнені, лишаються тільки зміни стану без руху. Canvas-тло ставиться на паузу, коли вкладка прихована (`visibilitychange`).

Готові напрацювання для реалізації: WarpSpeed.js / `starfield-effect` (зоряне поле), патерн lightsaber-checkbox на чистому CSS (scotch-io, MIT) — як основа для перемикача.

## 10. Модель даних (чернетка)

```ts
type Ability = 'str' | 'dex' | 'con' | 'int' | 'wis' | 'cha';

interface Character {
  id: string;
  name: string;
  species: string;            // e.g. "Twi'lek"
  classes: { name: SW5eClass; level: number; archetype?: string }[];
  abilities: Record<Ability, number>;
  hp: { current: number; max: number; temp: number };
  ac: number;
  speed: number;
  hitDice: { die: 'd6'|'d8'|'d10'|'d12'; total: number; spent: number }[];
  force?: { max: number; current: number; castingAbility: 'wis'|'cha'; maxPowerLevel: number };
  tech?:  { max: number; current: number; maxPowerLevel: number };   // castingAbility = int
  powers: { id: string; kind: 'force'|'tech'; level: number; side?: 'light'|'dark'|'universal' }[];
  conditions: string[];
  credits: number;
  inventory: Item[];
  updatedAt: string;          // для розв'язання конфліктів офлайн-синку
}

type SW5eClass = 'Berserker'|'Consular'|'Engineer'|'Fighter'|'Guardian'
               | 'Monk'|'Operative'|'Scholar'|'Scout'|'Sentinel';

interface Encounter {
  id: string; sessionId: string; round: number; activeIndex: number;
  combatants: { refId: string; type: 'pc'|'npc'; initiative: number;
                hp: { current: number; max: number }; conditions: string[];
                hiddenFromPlayers: boolean }[];
}
```

**Бізнес-правила:**
- `powerCost(level) = level + 1`
- `shortRest()` → `tech.current = tech.max`, витрата hit dice на вибір
- `longRest()` → `force.current = force.max`, `tech.current = tech.max`, `hp = max`, повернення половини hit dice

## 11. Технічний каркас (пропозиція)

- **Фронтенд:** PWA (Vue 3 + Vite або Livewire, якщо хочеться лишитися в екосистемі Laravel), Service Worker для офлайну, IndexedDB для локального аркуша.
- **Бекенд:** Laravel + **Reverb** (WebSocket) для live-бою. Як альтернатива — невеликий Go-сервіс на WebSocket, якщо потрібне високе навантаження.
- **Синхронізація:** last-write-wins за `updatedAt` на рівні полів. Бій — авторитетний сервер, GM — джерело істини.
- **Довідкові дані:** імпорт JSON-дампу правил у БД, версіонування за датою імпорту.
- **Вхід:** код кімнати (6 символів) + ім'я для гравців, акаунт — лише в GM.

## 12. Доступність

- Контраст WCAG 2.1 AA, видимий фокус (`--accent-blue`, 2 px outline + glow).
- Усі інтерактивні елементи — нативні `button` / `input`, ARIA лише там, де без неї не обійтися.
- Озвучення кидків через `aria-live="polite"`.
- Масштабування тексту до 200 % без поломки верстки.
- Режими «Високий контраст» (без світіння) і `reduced-motion`.
