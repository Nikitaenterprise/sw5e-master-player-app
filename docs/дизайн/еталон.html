Бронзова голограма

Так виглядає Holotable. Рідке скло скрізь, навіть на панелях, над туманністю й зорями. Бронзово-золоті рамки й підписи, сині числа й дані, приглушений червоний лише для тривоги. Жодних заокруглених кутів: тільки прямі й зрізані. Колір туманності — схильність персонажа, яку виставляє майстер: синій для Light, бронза для Balanced, глибокий червоний для Dark.
