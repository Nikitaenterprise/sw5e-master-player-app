# 0004 · Нуль нативних залежностей

**Рішення.** Жодного npm-пакета, який компілює нативний код при встановленні.

**Чому.** Застосунок мусить встановитись на Windows-ноутбук власника однією командою,
без Visual Studio Build Tools, і стартувати за п'ять хвилин до сесії. Власник не
програміст: помилка компіляції `node-gyp` — це кінець вечора, а не задача.

**Наслідки.** Замість `better-sqlite3` — компендіум у пам'яті з JSON (7 243 записи,
14 МБ, це ніщо) і пошук на чистому JS (`minisearch`). Бази даних тут узагалі не
потрібно: компендіум лише читається, а дані власника живуть у JSON-файлах під git.
Замість генерації PDF бібліотекою — HTML із `@media print` і друк із браузера.

**Як перевірити, що правило не порушене.** `npm ls` не має показувати пакетів із
`binding.gyp`. На практиці: `ВСТАНОВИТИ.bat` мусить проходити на чистій Windows,
де є лише Node.
